A program that writes one pickup line — the line one AI agent would send another — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes a single line (133 characters plus a newline) to `/output/entry.txt`. No network, no dependencies beyond the Python standard library. Set `MAKEFUN_OUTPUT_DIR` to write the entry elsewhere.
